# Rio portrait sources

The Rio portrait and expression assets in this directory are official in-game
Blue Archive artwork. The image files were retrieved on 2026-09-18 from the
Blue Archive Wiki mirror because the official announcement pages do not expose
the transparent story portraits as standalone downloads.

- Official Nexon Rio release notice:
  https://forum.nexon.com/bluearchive-en/board_view?board=3218&thread=3035106
- Gallery index and mirrored portrait files:
  https://bluearchive.fandom.com/wiki/Tsukatsuki_Rio/Gallery
